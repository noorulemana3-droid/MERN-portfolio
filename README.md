# Portfolio - MERN Stack Developer Intern

A modern, responsive, and production-ready developer portfolio built with **Next.js 15**, **TypeScript**, **Tailwind CSS**, and **Supabase** using a **single codebase architecture**. The portfolio showcases my skills, projects, experience, education, certifications, GitHub profile, and includes a fully functional contact system.

## 🚀 Live Demo

**Website:** https://mern-portfolio-lilac.vercel.app/

- Modern and responsive UI

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/your-repository.git
```

### Navigate to the project

```bash
cd your-repository
```

### Install dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env.local` file in the root directory.

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
GEMINI_API_KEY=your_gemini_api_key
```

### Start Development Server

```bash
npm run dev
```

Open:

```
http://localhost:3000
```

## 🌐 Deployment

This project uses a **single codebase** and is deployed on **Vercel**.

Deployment Steps:

1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Add the required environment variables.
4. Deploy the project.
